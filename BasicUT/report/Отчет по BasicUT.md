# Лабораторная работа 2

## BasicUT

### Цель работы

Познакомиться с модульным тестированием C++ без сторонних тестовых библиотек.

### Вариант

Выполнена общая часть работы.

### Выполненные задания

- созданы тесты для всех четырёх преобразований конвертера;
- добавлены проверки входного значения `0`;
- добавлены тесты отрицательного значения и неподдерживаемого типа;
- тесты имеют имена и выводят результат каждого запуска;
- тестовый раннер возвращает `0`, если все тесты пройдены, и `1`, если есть ошибка;
- раннер зарегистрирован в CTest.

### Сборка

```powershell
cmake -S . -B build
cmake --build build
```

### Запуск приложения

```powershell
.\build\BasicUT.exe --in 1500 --ct 0
```

Ожидаемый результат:

```text
1500 MillimeterToMeter equals 1.5
```

### Запуск тестов

```powershell
.\build\BasicUTRunner.exe
ctest --test-dir build --output-on-failure
```

Ожидаемый итог:

```text
Results: 6 passed, 0 failed
100% tests passed
```

### Вывод

Логика конвертации отделена от точки входа приложения. Тестовый раннер автоматически проверяет корректные преобразования и обработку ошибок.
