# Лабораторная работа 3

## Benchmark

### Цель работы

Научиться измерять время выполнения алгоритмов и проверять корректность сортировки.

### Вариант

Выполнена общая часть работы.

### Выполненные задания

- реализованы `BubbleSortClassic` и `std::sort`;
- таймер переведён на `std::chrono::steady_clock`;
- таймер выводит название операции и время в микросекундах;
- добавлены тесты для пустого вектора, одного и двух элементов;
- добавлены тесты для типов `int`, `double` и `std::string`;
- оба алгоритма получают копии одинаковых исходных данных;
- после сортировки выполняется проверка `std::is_sorted`;
- раннер зарегистрирован в CTest.

### Сборка

```powershell
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

### Запуск тестов

```powershell
.\build\BenchmarkUTRunner.exe
ctest --test-dir build --output-on-failure
```

В выводе для каждого типа данных отображается время `BubbleSortClassic` и `std::sort`. Конкретные значения зависят от компьютера.

### Анализ

`BubbleSortClassic` имеет квадратичную сложность `O(n²)`. Стандартная сортировка `std::sort` обычно работает за `O(n log n)`, поэтому при увеличении размера массива она масштабируется лучше.

Измерения выполняются в Release, потому что Debug отключает оптимизации и искажает сравнение производительности.

### Вывод

Оба алгоритма корректно сортируют проверенные типы данных. `std::sort` предназначен для практического применения, а пузырьковая сортировка используется для демонстрации квадратичной сложности.
