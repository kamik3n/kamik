# Лабораторная работа 1

## EnvironmentTest

### Цель работы

Проверить настройку C++-окружения, работу CMake и определить параметры сборки программы.

### Вариант

Вариант 1 — информация о сборке.

### Выполненные задания

- задан стандарт C++17;
- реализован вывод используемого компилятора и его версии;
- реализован вывод значения `__cplusplus`;
- добавлен вывод типа сборки Debug или Release;
- добавлен вывод разрядности платформы через `sizeof(void*)`;
- добавлен параметр `/Zc:__cplusplus` для MSVC;
- каталог `build` исключён из Git.

### Сборка

```powershell
cmake -S . -B build
cmake --build build
```

Для Release:

```powershell
cmake -S . -B build-release -DCMAKE_BUILD_TYPE=Release
cmake --build build-release
```

### Результат запуска

```text
EnvironmentTest OK
Compiler: GCC 14.3.0
C++ Standard (__cplusplus): 201703
Build type: Release
Architecture: 64-bit
```

Значение версии компилятора и путь к исполняемому файлу зависят от установленного компилятора и генератора CMake.

### Вывод

Проект успешно конфигурируется и собирается в C++17. Программа показывает компилятор, стандарт языка, тип сборки и разрядность платформы.
